# kiranasync

## Multilingual voice commands

Voice commands support Bengali, English/Hinglish, Gujarati, Hindi, Kannada, Malayalam, Marathi, Punjabi, Tamil, and Telugu using Gnani's documented STT language codes. Choose a voice-command language from the window header to send one transcription request, or leave it on auto-detect. Gnani's current REST STT API requires a language code and does not document built-in auto-detection; the app's auto mode therefore sends the audio once for each of the 10 supported language codes in parallel. Gemini Flash-Lite compares those alternative transcripts, selects the most plausible one, and extracts the action, product/customer, and whole-number quantity as structured JSON. Auto mode can be slower and uses up to 10 Gnani STT requests per command. The app validates the interpretation and performs inventory and customer-balance changes locally; unclear commands or quantities are rejected without database changes. The dashboard language can be selected independently from the dashboard's language menu.

The speech endpoint requires a valid `GNANI_API_KEY`; language understanding requires a valid `GEMINI_API_KEY`. Put both in the root `.env` file. The model defaults to `gemini-3.5-flash-lite`; set `GEMINI_MODEL` to override it. The API call sends the recognized transcript(s), inventory item names, and customer names to Google. For challenge demos, use synthetic data only and do not send real customer details or recorded calls. Google's unpaid Gemini service may use submitted content to improve its products; review the current API terms before using it with anything sensitive.

The dashboard transaction ledger keeps a timestamped history of sales, stock additions/restocks, and customer-credit entries, including the command or action details. Sales show a positive amount; restock costs show a negative amount calculated from the inventory item's current Price and the purchased quantity. Existing transaction tables are upgraded in place when the backend accesses them; previous records remain available.

Voice transactions and manual inventory/customer additions are read aloud and shown in an editable review dialog before they are applied. Correct the action, name, quantity/amount, or item price, then confirm; edited fields are read aloud when you leave them, and you can replay the complete summary. Cancelling the review makes no transaction changes. Speech is generated by Gnani Timbre v3.0 in the selected voice-command language, or in the detected STT language in auto-detect mode; the dashboard language does not affect TTS. For manual additions, TTS follows the voice-command language selector, falling back to English when it is set to auto-detect. `GNANI_TTS_MODEL` and `GNANI_TTS_VOICE` can override the model and voice.

When a spoken restock/new-product command names an item that is not in inventory, the app searches the web for MRP suggestions and opens a confirmation dialog with the item, quantity, prices, and result sources. If no relevant product result is found, a fallback search looks for close spellings in product-name results and offers likely similar names for the user to verify and search; it does not change the item or use a suggested name without selection. The dialog reads the initial product details aloud and has a replay button. If Timbre mispronounces a brand, enter a phonetic spelling in the optional pronunciation field and replay; this affects TTS only, while the actual product name is used for search and saved to inventory unchanged. Search retries common name variants and filters results against distinctive product-name words, ignoring generic item types such as "biscuit", so unrelated pages and prices are not displayed. Edit the name and search again to refresh its results. Select one or more price options, set the stock quantity for each, and confirm to add a separate inventory product for each selected MRP (the MRP is appended to each product name). You can also add an MRP manually. Search results are suggestions rather than verified live prices; check the product packaging/source before confirming.

If a sell/restock voice command matches multiple inventory variants of the same product, the app asks you to choose the exact item/MRP before changing stock.
